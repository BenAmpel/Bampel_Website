# Self-hosted Google Fonts

Fira Code, Merriweather, Playfair Display and Roboto Mono, downloaded from Google Fonts by
`scripts/self-host-google-fonts.mjs` so pages make no request to Google. All four are licensed under the SIL Open Font
License 1.1 (https://openfontlicense.org), which allows redistribution with the site.

Source stylesheet: https://fonts.googleapis.com/css2?family=Fira+Code:wght@400;700&family=Merriweather:ital,wght@0,300;0,400;0,700;1,300;1,400&family=Playfair+Display:wght@400;700&family=Roboto+Mono&display=swap
