Verification study: admin

Use the owner key (the VC_ADMIN_KEY Netlify variable) or the team key the owner gave you. It is kept in this tab only.

Add students

Paste student emails, one per line or separated by commas. Only these emails can sign in. Each student creates a 4-digit PIN at first sign-in. Emails are not stored: the server keeps a one-way keyed hash, so exports stay de-identified. Conditions are assigned in balanced blocks of three across all batches. Emails already enrolled are skipped.

Check completion

Paste emails to see who has finished, for awarding credit. Emails are looked up, not saved.

Reset a PIN

For a student who forgot their PIN or is locked out. They create a new PIN at their next sign-in. Their progress is kept.

Create pilot access codes

For pilots and team testing without a roster. Mark them as test so they are excluded from the counts and can be deleted in one step. Gap days sets the minimum wait between sessions (0 for piloting).

No unsaved changes.

Versions

Every save makes a new version. Restoring an old version saves it again as the newest version, so nothing is lost. Each answer records the version it was collected under.

Add a team member

Each person gets their own key. Share it privately. Removing a person disables their key immediately.
