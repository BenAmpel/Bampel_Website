# Font Awesome subsets

Written by `scripts/subset_fontawesome.py`: Font Awesome Free 6.4.0 (fonts under the SIL Open Font License 1.1,
icons CC BY 4.0) cut down to the icons the site uses. They override the theme's full fonts of the same names.
Icons in use when written: fa-bars, fa-camera, fa-compass, fa-creative-commons, fa-creative-commons-by, fa-creative-commons-nc, fa-creative-commons-nd, fa-envelope, fa-facebook, fa-file-alt, fa-file-pdf, fa-flask, fa-linkedin, fa-linkedin-in, fa-map-marker, fa-search, fa-shield-halved, fa-times-circle, fa-trophy, fa-twitter, fa-weibo, fa-whatsapp.
